# Robot Failure Detection Website

This repository hosts the static site for `robotfailuredetection.com`.

## Contents

- `index.html` - landing page and benchmark table
- `styles.css` - site styling and responsive layout
- `CNAME` - custom domain for GitHub Pages
- `.nojekyll` - disables Jekyll processing on GitHub Pages
- `.github/workflows/pages.yml` - GitHub Pages deployment workflow
- `robots.txt` - crawler instructions
- `sitemap.xml` - site sitemap

## Deployment

The site is designed to deploy through GitHub Pages from the `main` branch.

1. Push this repository to GitHub.
2. Enable GitHub Pages in the repository settings.
3. Select the GitHub Actions source.
4. Verify the custom domain is set to `robotfailuredetection.com`.

## DNS

At your domain registrar, point `robotfailuredetection.com` to GitHub Pages using the standard GitHub Pages custom domain instructions.

## Local Preview

This project is static HTML and CSS. You can preview it with any local web server.
